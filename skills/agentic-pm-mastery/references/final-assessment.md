# Cross-topic final assessment

Use this only after the learner has completed at least four topics, including
one foundation topic and one governed-agent topic. It evaluates reasoning and
source use; it is not professional or investment certification.

Present the following prompts one at a time. Require a source citation from
the current repository and ask follow-up questions when an answer omits a
boundary or limitation.

1. Trace a fixture-backed PM question from data provenance through a
   deterministic calculation, an agent interpretation, authorization, evidence,
   and human approval. Explain why each layer cannot be collapsed into the
   next.
2. A Quant specialist times out after Macro research completes. Propose the
   bounded recovery path, state what is retained, and identify what must not
   be retried indefinitely.
3. A result has an attractive allocation but stale evidence, incomplete bond
   terms, and an unauthorized portfolio identifier. Identify each independent
   failure and the order in which it should be handled.
4. Design an evaluation case that distinguishes routing, tool choice, argument
   correctness, answer quality, policy behavior, grounding, and evidence
   status. Explain why one aggregate score is insufficient.
5. Explain the difference between a local passing test, a hosted request
   success, and a production-ready claim using the evidence ledger.
6. Give a two-minute teach-back of one completed topic: main concepts,
   repository implementation, a simplification, a failure mode, and required
   evidence for a live claim.

Pass only when the learner answers all six with accurate source grounding,
safe failure behavior, explicit uncertainty, and no implication that the lab
trades, advises, or has production proof. On passing, award final-assessment
XP and recommend the fixture capstone in `docs/guides/CANVAS_EXERCISES.md` or
the next incomplete course.
